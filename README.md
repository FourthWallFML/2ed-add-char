# AD&D Kroniek - Forgotten Realms PWA

Een responsieve Advanced Dungeons & Dragons (AD&D) Progressive Web App (PWA) in een perkament- en leerstijl, vooraf gevuld met de personen, locaties en monsters uit de campagneverslagen.

## Installeren via GitHub Pages
1. Upload `index.html`, `manifest.json` en `sw.js` naar je GitHub-repository.
2. Ga in je repository naar **Settings > Pages**.
3. Kies bij **Source** voor `Deploy from a branch`, selecteer `main` en klik op **Save**.
4. Open de gegenereerde GitHub Pages URL op je smartphone en kies in je browsermenu voor **Toevoegen aan startscherm** / **App installeren**.
