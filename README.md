# AD&D Kroniek - Forgotten Realms PWA

Een compacte, volledig aanpasbare Advanced Dungeons & Dragons (AD&D) Progressive Web App (PWA) met jouw eigen perkament/leer-achtergrond en app-icoon.

## Bestanden in deze repository
- `index.html`: De volledige app (compact karakterblad, XP/Level-up, inventaris, NPC's & plaatsen, monster dodenlijst, dobbelstenen).
- `manifest.json`: Configuratie voor installatie op smartphone/desktop.
- `sw.js`: Service Worker voor offline gebruik.
- `bg.jpg`: Achtergrondafbeelding van het perkament en leer.
- `icon-192.png` & `icon-512.png`: App-icoon voor het startscherm.

## Installeren via GitHub Pages
1. Upload alle bestanden uit de zip naar je GitHub-repository.
2. Ga naar **Settings > Pages**, kies `Deploy from a branch` (`main`) en klik op **Save**.
3. Open de GitHub Pages URL op je smartphone en kies **Toevoegen aan startscherm**.
